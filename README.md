# Receitas de Programação Web (PWeb)

Este repositório contém a implementação das atividades práticas (Receitas) da disciplina de Programação Web. Como a API original solicitada nas instruções (Random Data API) estava fora do ar, as receitas foram adaptadas utilizando APIs públicas alternativas.

## 📂 Estrutura do Projeto

* **[Menu Principal](./index.html)**: Página raiz com links para todas as receitas implementadas
* **[Receita 1 - Lista de Usuários](./receita1/index.html)**: Utiliza a `JSONPlaceholder API` e Promises tradicionais (`.then()`).
* **[Receita 2 - Lista de Pokémon](./receita2/index.html)**: Utiliza a `PokeAPI` com a sintaxe moderna `async / await`.
* **[Receita 5 - Arrow Functions e Map](./receita5/index.html)**: Utiliza a `FakeStore API`, implementada com Arrow Functions (`=>`) e métodos de array (`.map()`) para renderização dinâmica em tabela.

## 🛠️ Tecnologias Utilizadas
* HTML5 / CSS3
* JavaScript Vanilla (ES6+)
* Fetch API
